# 核心页面低保真原型与视觉方向

Type: prototype
Status: resolved
Blocked by: 06

## Question

用低保真原型把四个核心视图和关键交互具体化，验证信息密度、层级与视觉方向是否适合「开发者选型工作台」。

需要产出：

- 可点击或可浏览的低保真原型（HTML / 截图 / 线框均可），至少覆盖：探索对比表、模型详情、并排对比、榜单；含桌面与移动端关键状态。
- 用真实的 8-12 个模型样例数据（含价格、上下文、推理等级、评测、缺失数据）填充，避免占位符掩盖问题。
- 验证 3-5 个关键场景：按预算 + 上下文筛选；比较两个模型的能力 / 价格；查看某模型的推理等级与评测来源；从榜单跳到详情；数据缺失时的呈现。
- 给出视觉方向建议：数据密度、字体 / 数字排版、颜色语义（好坏 / 缺失 / 来源）、图表风格；只到低保真，不做完整设计系统。
- 记录用户反应与待修问题，回写到「信息架构与核心交互」或新票。

约束：中文界面；四个视图；不实现生产逻辑；资产链接回本票，不粘贴大段代码。

## Prototype

- 可浏览：[prototype/index.html](../prototype/index.html)（打开方式与场景见 [prototype/README.md](../prototype/README.md)）。
- 三个视觉方向：A Workbench / B Cards / C Editorial；`?variant=` 或底部浮动条切换。
- 四个视图与 5 个场景已实现；12 个真实样例，含缺失分数、网关 / 已弃用报价。
- 待评审：视觉方向、表格密度、详情顺序、对比字段、移动端。

## Answer

**决定（2026-10-26）**

- 用户选择 **A · Workbench**：左侧筛选 + 高密度表格；B Cards / C Editorial 作为备选丢弃。
- 已验证：四个视图（探索表、详情、对比、榜单）可切换；5 个场景可走通；筛选 / 排序 / 搜索、对比托盘（最多 3）、详情报价折叠（网关 / 已弃用）、缺失分数、移动端卡片与筛选抽屉都可用。
- 原型资产：[prototype/index.html](../prototype/index.html)；说明见 [prototype/README.md](../prototype/README.md)。
- 数据发现：Arena `webdev/latest` 含多个 category 和多日期行，已写入「数据管道与更新策略」；原型只取 `category=webdev`（webdev）和 `overall`（text）。
- 后续字体、颜色、间距等视觉细节以 A 为基线，在最终规格与实现阶段收敛；B / C 不再作为主方向。
