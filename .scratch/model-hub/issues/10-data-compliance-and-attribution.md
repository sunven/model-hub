# 数据合规、署名与外链策略

Type: grilling
Status: resolved
Blocked by: 01, 12

## Question

在公开站点上展示第三方数据，哪些内容需要署名、免责声明或直接外链，才能把许可与 ToS 风险降到可接受？

需要定下：

- 每个数据源的许可 / 条款结论（以「数据源可得性、授权与字段」为准）：可嵌入、需署名、仅可链接、不可用。AA 的最终呈现方式（外链 / 许可）以「评测数据源组合与 AA 授权策略」为准；本票负责对应的署名、免责声明和外链处理。
- 署名位置与文案：页脚、模型详情、榜单页、图表角落；是否展示源站链接和抓取时间。
- 价格与汇率：USD / CNY 折算的汇率来源、更新频率、免责声明；是否展示「以供应商官网为准」。
- 商标与模型名：供应商 / 模型名称的使用边界；是否需要「非官方」声明。
- 缺失 / 错误数据的纠错入口：邮件 / Issue 链接或表单（最小方案）；是否需要隐私政策 / 服务条款页面。
- 对外链的处理：nofollow、target、失效链接的降级。

约束：免费公开数据、不抓取、不付费；公开中文站点。产出是合规与署名清单，直接进入规格和页面文案。

## Answer

**决定（2026-10-27）**

### 1. 署名与许可页面

- **页脚常驻**：models.dev（MIT）来源链接、Arena HF（CC BY 4.0）来源链接、Artificial Analysis 外部链接说明、价格 / 汇率免责、非官方声明、`/about` 链接。
- **`/about` 数据说明页**：
  - models.dev：链接 + MIT License 链接，并保留 MIT 版权 / 许可声明文本；说明我们使用模型 / 价格 / 限制 / 推理选项等字段。
  - Arena：链接到 `lmarena-ai/leaderboard-dataset` + CC BY 4.0 许可链接 + “LMArena” 署名；说明修改：按 category / 最新日期 / 最高票筛选、映射到 Model Version、展示格式调整，未改变评分含义。
  - Artificial Analysis：明确“仅外部链接，不嵌入数据、不调用 API、不展示 AA 分数”，不暗示合作或背书。
  - 汇率：`data/fx.yml` 人工维护，页面显示 rate / as_of；说明 CNY 仅为便利信息。
  - 非官方 / 商标：不使用第三方 logo；模型与供应商名仅作名称指称；所有商标归各自所有者。
  - 隐私：无账号、无评论、无 cookie、无分析；静态托管商可能记录访问日志，详见托管商隐私政策；无 cookie banner。
  - 纠错 / 下架：GitHub Issues 链接 + 模板（数据纠错 / 下架请求 / 权利说明）。仓库 URL 上线前必须补齐；若最终没有公开仓库，改用邮箱，但不得留空。
- **区块级署名**：探索表底部、详情 Arena 区块、榜单页顶部都带来源 + 日期 + 许可提示；具体文案由规格统一。
- 不单独做 `/privacy` / `/terms`：首版没有账号、交易、分析或 cookie，`/about` 足够；若以后加分析 / 账号，再拆页并重新评估 consent。

### 2. 外链与商标

- 外部链接：新窗口 + `rel="noopener noreferrer"`；引用来源不加 `nofollow`；未来若出现付费 / 赞助链接再单独评估。
- 不使用供应商 / 模型 logo、不热链第三方图片；只使用文本名称。
- AA 链接统一标「外部评测 · Artificial Analysis」；有稳定模型 URL 则链模型页，否则回退 AA 总榜；链接失效时降级为总榜。
- 非官方声明放在页脚与 `/about`；不得使用“官方”“合作”“认证”等措辞。
- 价格 / 汇率免责：数据为快照，实际以供应商官网为准；CNY 折算仅供参考，不构成交易建议。

### 3. 汇率与价格

- `data/fx.yml` 字段：`usd_to_cny`、`as_of`、`source`（人工参考来源）、`reviewed_at`（可选）。
- 每周人工复核；页面显示 rate / as_of；若 `as_of` 超过 14 天，隐藏 CNY，仅显示 USD，并在 `/about` 说明。
- 不接 FX API、不做实时汇率、不构成金融建议。
- USD 为源数据主币种；CNY 只在展示层折算，不落库。

### 4. 纠错与下架

- 首选 GitHub Issues：提供模板（目标 URL / 字段 / 当前值 / 建议值 / 来源）；公开可追踪。
- 权利方下架请求走同一入口；按“先隐藏、后核实”处理，保留内部记录。
- 仓库 URL 是上线前 TODO；若项目不公开，则改为邮箱，但必须在上线前确定。

### 5. 上线前复核

- 本票是产品口径，不构成法律意见；上线前人工复核 models.dev / Arena / AA 的最新条款。
- 若 models.dev 的 MIT 许可对贡献数据覆盖不清，向维护者确认；若 AA 对链接使用有额外限制，调整文案或移除链接。
- 不抓取 arena.ai / AA，不绕过 403，不付费；现有数据只来自 models.dev 与 Arena HF 官方数据集。
